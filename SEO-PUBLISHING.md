# Publishing the HVAC and MEP service update

This update adds two substantive service pages, clearer homepage headings and metadata, direct contact links, service-to-project links, and an updated sitemap. It is prepared for the existing GitHub Pages site at https://mackeygrip.github.io/.

## Upload in Codespaces

Use the complete `Mac-Key-Grip-Visual-Portfolio-Update.zip` and the commands in [VISUAL-PUBLISHING.md](VISUAL-PUBLISHING.md). It includes these service pages together with the new portfolio artwork. Do not apply the earlier SEO-only ZIP after the visual update, because it contains older versions of shared pages.

## After deployment

Open both pages and check the project links and contact buttons:

- https://mackeygrip.github.io/services/hvac-air-conditioning-design-zambia.html
- https://mackeygrip.github.io/services/mep-design-coordination-zambia.html

In the existing Search Console property, inspect each new URL, test the live URL, and request indexing if it is accessible and eligible. Inspect the updated homepage as well.

The sitemap address stays the same: https://mackeygrip.github.io/sitemap.xml. Check that Google can read it and discover the two new URLs. There is no need to create a second property.

## Measure visibility

In Search Console, use Performance → Search results → Queries. Compare equal periods, initially after enough time has passed to collect data (for example, 28 days before versus 28 days after deployment). Track impressions, clicks and average position for queries containing HVAC, air conditioning, air-conditioning, ventilation or MEP; filter by Zambia when useful.

With new service pages there is no earlier page-level baseline, so inspect their impressions and queries separately. Search Console omits some queries for privacy. Personal searches vary by location, device and history and do not establish a consistent rank.

Search visibility is not guaranteed. Google may take weeks or longer to reflect changes. Requesting indexing is a discovery step, not a ranking boost. Do not add duplicate pages for every wording, invisible keyword lists, invented project outcomes, paid links or fabricated reviews.
